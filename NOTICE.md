# Saiko reference catalogue: attribution and notices

Adapted from [Piru](https://github.com/kageroumado/piru), maintained by kageroumado
and upstream contributors. Saiko preserves source attribution and citations
inside the database. `sources.json` lists every recorded source; the manifest
records the upstream revision and original bytes when available.

Saiko changes include separating therapeutic monitoring references from effect
thresholds, preserving receptor subtypes in interpretation, and correcting the
dose.wiki mushroom article's association from isolated psilocybin to the mushroom
preparation. Database attribution is not endorsement of every claim.

These are the notices carried by the upstream app, retained rather than replaced
by a single licence for the entire mixed-source catalogue:

  merged with other sources; those contributions remain under CC BY-SA 4.0.
- [dose.wiki](https://dose.wiki), [Wikidata](https://www.wikidata.org), and

The full GPL, CC BY-SA, CC0 and LGPL texts accompany this release in `licenses/`.
This package contains only reviewed reference data and these notices. It does
not contain the app's user journal, inventory, settings, backups, or credentials.
Unknown source retrieval dates remain absent rather than being replaced by the
release date. Scientific limitations and corrections are described in release notes.
